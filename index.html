// features

    
A real agent, not autocomplete.

    
Kodr plans, uses tools and checks its own work, and asks before it changes anything.

    

      
[any-model]
Bring any LLM
Claude, GPT, Gemini, DeepSeek, Mistral, or anything OpenAI-compatible. Switch models mid-session with one command.

      
[local]
Runs fully local
Point it at Ollama or LM Studio and nothing leaves your laptop. No account, no telemetry.

      
[tools]
Reads, edits, runs
Searches your codebase, makes precise diff-based edits, runs tests and shell commands, and uses git.

      
[safe]
You stay in control
Every file write and command asks first. Set rules per project: allow, ask or deny.

      
[cost]
See what you spend
Live token and cost tracking per model and per session, so cheap models handle the easy work.

      
[context]
Knows your project
Drop an AGENTS.md in your repo with conventions and commands. Sessions resume where you left off.

// get started

    
Up and running in a minute.

    
Python 3.10 or newer. Works on macOS, Linux and Windows (WSL).

    

      
Install
One command, isolated from your system Python.
pipx install kodr

      
Add a model
Use a key you already have, or go local for free.
export ANTHROPIC_API_KEY=...
# or: ollama pull qwen2.5-coder

      
Start coding
Open any project and tell it what you need.
cd my-project
kodr

    

  






  

    
// faq

    
Questions

    
Is Kodr free?
Yes. Kodr itself is free to use. You pay your model provider directly for usage, or nothing at all with a local model.

    
Does my code get sent anywhere?
Only to the model provider you choose. Kodr has no servers and no telemetry. With a local model, nothing leaves your machine.

    
Which model should I use?
For hard multi-file work, a frontier model like Claude or GPT. For quick edits, a cheaper or local model. You can switch at any time with /model.

    
Can it break my project?
Kodr asks before every edit and command by default, shows diffs before writing, and works well alongside git, so every change is reviewable and reversible.
